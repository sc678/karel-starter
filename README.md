# Karel the Robot

My work from the Karel weeks of COSC 10001 at TCU. This repository contains my Karel program and the work I completed while learning basic programming concepts.

I learned:
* How to use move(), turnLeft(), pickBeeper(), and putBeeper() to control Karel.
* Learned that Karel must be in the correct location before picking up or placing a beeper.
* Practiced checking my code for walls, correct commands, and matching braces before running it.
